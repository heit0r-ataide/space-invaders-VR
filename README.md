# space-invaders-VR
Projeto que estava "abandonado" a quase 2 anos, que foi criado no meu 2° ano do ensino médio, o projeto é um jogo feito no python utilizando a biblioteca pygame e sys, sendo uma réplica do clássico Space Invaders, porém com uma inovação de ter a opção de jogar com um óculos de realidade vitual caseiro. Não vou mentir, na época deu muito trabalho.
